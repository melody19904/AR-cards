# CARD VISION Release Process

## Before Release

Verify that the application builds, camera permission works, scanner starts/stops, flashlight works, card recognition works, server connection works, vault persists, render assets load, animations load, WebView navigation works, settings work, and no secrets are packaged.

A release should be tested on a real Android device. Emulator-only verification is insufficient for camera and AR functionality.

## Versioning

Use semantic versioning where practical: `MAJOR.MINOR.PATCH`.

## Release Notes

Document new features, bug fixes, breaking changes, known issues, asset changes, and backend changes.
