# Repository Setup

## Requirements

Typical development requirements include Git, Android Studio, Android SDK, a compatible JDK, Python where backend tooling is used, and access to required backend services.

## Clone

```bash
git clone <repository-url>
cd CARD-VISION
```

## Android

Open the project in Android Studio and allow Gradle to synchronize. Do not commit local IDE state or generated build output.

## Backend

Use environment variables. Refer to `.env.example`. Never commit production credentials.

## Media

Documentation media is stored under `docs/media/` and includes application screenshots and the Blue Omelett prototype.
